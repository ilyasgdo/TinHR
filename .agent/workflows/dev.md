# Workflow de Développement FlashJob

## Avant de commencer à coder
1. Lire `ai/PROGRESSION.md` pour connaître l'état actuel du projet
2. Lire `ai/REGLES.md` pour se rappeler les contraintes
3. Ouvrir le fichier de l'étape en cours dans `ai/etapes/ETAPE_X_*.md`
4. Vérifier que l'étape précédente est bien complétée (toutes les cases cochées)

## Pendant le développement
5. Commencer par la première case non cochée de l'étape en cours
6. Coder la fonctionnalité
7. Tester la fonctionnalité
8. Cocher la case dans le fichier d'étape
9. Git commit avec message conventionnel
10. Répéter jusqu'à ce que toutes les cases soient cochées

## Après chaque étape complétée
11. Valider TOUS les critères de validation de l'étape
12. Mettre à jour `ai/PROGRESSION.md` (statut + pourcentage)
13. Remplir la section "Ce qui a été fait" dans le fichier d'étape
14. Passer à l'étape suivante
